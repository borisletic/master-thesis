# arXiv preprint source

`main.tex` is a self-contained LaTeX source (standard packages only) that compiles
on arXiv's TeX Live and locally.

## Build
```bash
pdflatex main.tex && pdflatex main.tex   # twice for refs
```
Figures are in `figures/` (copied from `../figures/`, regenerate with
`python -m scripts.make_figures`). `mitigation_result.tex` is generated by
`python -m scripts.analyze_mitigation`.

## arXiv submission
Upload `main.tex`, the `figures/` directory, and `mitigation_result.tex`. No
`.bib` file is needed (references are inline in `thebibliography`).
